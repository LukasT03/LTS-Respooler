LTS Utility for macOS lets you flash your ESP32 or LTS Control Board with the newest version from GitHub. Using the web flasher at https://flash.lts-design.com is the preferred way if you're on Windows.

The LTS Control app can be downloaded from the [App Store](https://apps.apple.com/app/lts-control/id6742149969). An Android version is in early development. For now, you can use the [Web version](https://control.lts-design.com/).

## 📱 The apps have separate repos that are linked below
- 🍏 iOS: https://github.com/LukasT03/LTS-Control-iOS
- 🤖 Android: https://github.com/LukasT03/LTS-Control-Android
- 💻 LTS Utility (macOS): https://github.com/LukasT03/LTS-Utility
