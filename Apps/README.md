The LTS Control app can be downloaded from the [App Store](https://apps.apple.com/app/lts-control/id6742149969) and on [Google Play](https://play.google.com/store/apps/details?id=de.ltsdesign.ltscontrol). There is also a [Web version](https://control.lts-design.com/).

The LTS Utility for macOS lets you flash your ESP32 or LTS Control Board with the newest version. Download [here](https://github.com/LukasT03/LTS-Utility/releases/latest/download/LTS-Utility.zip). Using the web flasher at https://flash.lts-design.com is the preferred way if you're on Windows.

## The apps have separate repos that are linked below
- 🍏 iOS: https://github.com/LukasT03/LTS-Control-iOS
- 🤖 Android: https://github.com/LukasT03/LTS-Control-Android
- 💻 macOS: https://github.com/LukasT03/LTS-Utility
